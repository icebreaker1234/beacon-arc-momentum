# Beacon Arc website

## Build
- Create a shared site shell with a sticky accessible header, geometric Beacon Arc wordmark, mobile navigation, and complete footer.
- Establish a dark ink, warm off-white, and luminous cyan design system with confident typography, precise grids, visible focus states, and reduced-motion support.
- Build the homepage as a business-first story: hero, friction, connected workflow shift, services, selected concept work, process, trust principles, and closing contact prompt.
- Create an original arc-to-workflow visual that progresses with natural page scrolling and resolves into a polished software interface; keep all core content readable without animation.
- Add optional lightweight Web Audio ambience, off by default, user-initiated, keyboard accessible, remembered in the browser, and disabled on touch devices.
- Build dedicated Services, Work, co-living platform case study, About, Contact, Privacy, and Terms pages with unique metadata and working navigation.
- Implement contact form validation and honest submission messaging that clearly states when delivery setup is still required.

## Content and trust
- Use plain language for non-technical business owners and make each service’s audience, problem, deliverables, first project, and next step clear.
- Label the co-living operations platform as a product concept and present only illustrative, non-claimed outcomes.
- Keep contact information editable and visibly marked as pending rather than inventing details.

## Quality checks
- Verify all routes and interactions, desktop and mobile presentation, keyboard access, reduced-motion behavior, and responsive text/layout.
- Review the complete homepage and central contact flow in the running preview; fix any build, console, or layout issues found.
